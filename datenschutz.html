Datenschutzhinweis

Diese Anwendung ist eine private Testanwendung. Sie wird ausschließlich vom Betreiber für eigene Zwecke genutzt und steht anderen Nutzern nicht zur Verfügung.

Welche Daten

Mit Zustimmung des angemeldeten Google-Kontos liest, erstellt und bearbeitet die Anwendung Dateien in Google Drive, Google Docs und Google Tabellen dieses Kontos.

Zweck

Die Daten werden ausschließlich zur Verwaltung der eigenen Dokumente und Tabellen des Betreibers verwendet.

Verarbeitung und Weitergabe

Zugangsdaten werden auf einem privaten Server des Betreibers gespeichert. Zur Verarbeitung können Inhalte an vom Betreiber genutzte KI-Dienste (Anthropic, OpenAI) übermittelt werden. Darüber hinaus werden keine Daten an Dritte weitergegeben, verkauft oder für Werbung genutzt.

Die Nutzung der über Google-APIs erhaltenen Informationen entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden.
